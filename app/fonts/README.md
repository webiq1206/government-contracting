# Self-hosted web fonts

Inter and Manrope, variable weight, Latin subset, as served by Google Fonts
and loaded through `next/font/local` in `app/layout.tsx`.

Both families are licensed under the SIL Open Font License, Version 1.1,
which permits bundling and redistribution with software.

- Inter: Copyright 2016 The Inter Project Authors (https://github.com/rsms/inter)
- Manrope: Copyright 2018 The Manrope Project Authors (https://github.com/sharanda/manrope)
